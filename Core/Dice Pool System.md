#Core-Mechanics
Everyone passively has a pool of 4d6 which should just be set aside 

Players can choose to roll a number of dice at the start of the round, which gets put in their action pool

Any dice that haven't been rolled will be instead set aside to their reaction pool, which can be used for the purpose of dodging.

During combat, any action die that have not been spent post-rolling will not be able to be carried over to the reaction pool, as a sign of hesitance to act and being too unprepared to react with that dice.

Outside of combat, any skill-based rolls should be rolled with **3d6**, adding any bonuses you have.
