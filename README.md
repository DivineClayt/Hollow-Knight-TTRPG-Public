This is a TTRPG based off the game Hollow Knight and its successor, Hollow Knight: Silksong. This TTRPG deviates a lot from standard TTRPG's such as D&D in a lot of aspects, and there is a lot to learn, but fear not! What I'll provide below is a simple index which gives you a nice order on how to learn my system! From learning about the dice pool system to your new health and SOUL system to the new take on combat through a 2 dimension grid that you perceive as if you're watching it sideways rather than over-the-top like typical ttrpgs!
